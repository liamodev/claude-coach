# Framework Workbook

Progress tracker for your coaching framework or program.
Answers are captured during coaching sessions and recorded here.

**Status key:** `[ ]` not started · `[~]` discussed, answer in progress · `[x]` answered

---

## How to Use This File

This file is optional. Use it if you're working through a structured coaching program, book, or methodology that has defined questions or exercises.

**To set it up:**
1. Replace the example lesson/section structure below with your framework's actual questions
2. Use the same status markers (`[ ]`, `[~]`, `[x]`) to track progress
3. Claude will read this file at the start of each session (via `/start`) and integrate the next unanswered questions naturally into the conversation

**If you don't have a workbook-style framework**, delete this file. The system works fully without it.

## Tips for Framework Owners

- Break your framework into named sections (lessons, modules, phases, etc.)
- Put the questions in the order they should be worked through
- Each question gets one status marker and one answer block
- When a question is answered in session, Claude updates the status and captures the answer
- Partially answered questions use `[~]` — come back to them
- Fully answered questions use `[x]` and keep the answer for reference
