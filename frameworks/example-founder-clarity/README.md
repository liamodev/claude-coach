# Example Framework: Founder Clarity

This is a ready-to-use example framework included with Claude Coach. It covers four areas that matter most in the early-to-growth stages of building a company: vision, decisions, energy, and beliefs.

**It's fully original — no copyright issues.**

---

## How to Activate This Framework

Copy the three items from this folder up to `frameworks/`:

```
frameworks/example-founder-clarity/guides/          → frameworks/guides/
frameworks/example-founder-clarity/guides_index.md  → frameworks/guides_index.md
frameworks/example-founder-clarity/workbook.md      → frameworks/framework-workbook.md
```

Or just point Claude to this folder during a session — it can read from here directly.

---

## What's Included

| Guide | What it covers |
|-------|---------------|
| `vision-and-direction.md` | Clarifying where you're going and why it matters |
| `decision-filter.md` | A simple filter for making hard calls under pressure |
| `energy-and-rhythm.md` | Protecting your operating energy as a founder |
| `beliefs-and-identity.md` | Surfacing and shifting the beliefs that limit performance |

The workbook (`workbook.md`) contains 20 questions across four modules, worked through progressively in sessions.

---

## Customizing It

Replace or extend any guide with your own material. The system works with any content — a book you're reading, a program you're in, tools from a mentor or advisor. See `frameworks/README.md` for how to build your own.
